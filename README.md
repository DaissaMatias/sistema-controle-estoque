# Sistema de Controle de Estoque

Projeto acadêmico desenvolvido para o curso de Análise e Desenvolvimento de Sistemas (ADS) da GRAN Faculdade.

## 📌 Funcionalidades
- Cadastro de Fornecedores
- Cadastro de Produtos
- Associação e Desassociação de Fornecedores a Produtos (Relacionamento N:N)

## 🗄️ Estrutura do Banco de Dados
O script para criação das tabelas e relacionamentos está localizado em `database/schema.sql`.
